Offline map packs for the Yehsa app. Each file is a raster MBTiles pack: terrain (hillshade, contours), land cover, water, trails, public-land outlines, place and peak names. No road layer. No parcel or owner layer.

Data: AWS Terrain Tiles (USGS 3DEP, SRTM, GMTED, ETOPO1; public domain). NLCD 2021 Land Cover (USGS/MRLC; public domain). Water, trails and protected areas: © OpenStreetMap contributors, ODbL 1.0. Natural Earth state outlines (public domain). May be dated.

Built by tools/mappacks/build_all.sh. The app checks each file's MD5 after download. Do not rename the files.
