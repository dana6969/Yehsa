# Landscape reference drop folder

Original notes on biomes, terrain, watersheds, coasts, mountains, deserts, forests, arctic and tundra country, river cues, natural landmarks, climate bands, magnetic declination, contours, and map-and-compass work.

This is the offline landscape layer: the kind of terrain knowledge a handheld can use without a city map. There is no street list, no town directory, and no point-of-interest catalog.

Add more `.txt` or verse `.json` files and run `npm run books:ingest`.

Offline reference only. Not a survey, not a live declination feed, and not a permit to travel closed land.
