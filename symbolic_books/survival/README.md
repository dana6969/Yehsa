# Survival reference drop folder

Original field notes: water, shelter and fire, navigation, weather, tools and cordage, signaling, food versus foraging, and camp. Each file is several short notes Yehsa can search offline. Signaling here means being found. It is not radio exploitation.

Add more `.txt` or `.json` files and run `npm run books:ingest`.

Offline reference only. Not a substitute for emergency services, rescue training, or medical care. Not a foraging menu and not a dose guide.
