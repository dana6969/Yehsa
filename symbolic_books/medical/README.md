# Medical drop folder

Yehsa already indexes these committed term lists as names only (no invented clinical definitions):

- `symbolic_memory/medical_terms_only.txt`
- `codesante_en.txt`
- `glutanimate.txt`

`desc2023.xml.gz` and `desc2024.xml` are HTML error pages, not medical datasets, and are not indexed.

Add your own `.txt` or verse `.json` files here and run `npm run books:ingest`. Do not commit copyrighted textbooks.

This store is offline reference for a survival-oriented agent. It is not medical advice and not a substitute for emergency services.
